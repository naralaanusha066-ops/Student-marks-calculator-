# 🎓 Student Marks Calculator

## 📝 About This Project
This is a simple Python project made for beginners. It takes a student's marks in 5 subjects and calculates Total Marks, Percentage, and Grade automatically.

## ✨ Features
- Student Name teesukuntundi
- 5 Subjects: Telugu, English, Maths, Science, Social
- Total Marks / 500 lo calculate chesthundi
- Percentage calculate chesthundi
- Marks ni batti Grade isthundi

## 🏆 Grade System
- 90% and above = A+ (Excellent)
- 75% to 89% = A (Very Good)
- 60% to 74% = B (Good)
- 40% to 59% = C (Pass)
- Below 40% = Fail

## ▶️ How To Run
python marks.py
